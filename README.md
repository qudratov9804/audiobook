# AI Audiobook Platform

REST API (Laravel 13 / PHP 8.4) for uploading books, organizing them into
sections (chapters) with audio files, and streaming/downloading the results.
Includes a Filament v4 admin panel and OpenAPI docs generated by Scramble.

## Stack

- Laravel 13, PHP 8.4, MySQL 8+ (SQLite for local dev)
- Laravel Sanctum (API token auth)
- Filament v4 admin panel at `/admin`
- `dedoc/scramble` API docs at `/docs/api`
- Database-backed queues (Supervisor in production)

## Local setup

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite   # if using the default sqlite connection
php artisan migrate --seed
php artisan storage:link
```

Seeding creates languages, categories, and an admin user (`ADMIN_EMAIL` /
`ADMIN_PASSWORD` in `.env`, defaults to `admin@audiobook.test` / `password`).

Run the app:

```bash
php artisan serve
php artisan queue:work
```

- Admin panel: `http://localhost:8000/admin`
- API docs: `http://localhost:8000/docs/api`

## Tests

## Deployment (Ubuntu 24.04)

Prerequisites on the server: Nginx, PHP 8.4-FPM (with `mbstring`, `curl`,
`pdo_mysql`, `fileinfo`, `zip`, `gd`, `bcmath`, `intl`, `sodium`), MySQL 8+,
Composer, Node.js LTS, Supervisor, Git.

```bash
git clone <repo> /var/www/audiobook
cd /var/www/audiobook
composer install --no-dev --optimize-autoloader
cp .env.example .env   # then edit: APP_ENV=production, APP_DEBUG=false,
                        # APP_URL, DB_*, CORS_ALLOWED_ORIGINS, ADMIN_*
php artisan key:generate
php artisan migrate --force --seed
php artisan storage:link
chown -R www-data:www-data storage bootstrap/cache

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan scramble:cache
```

**Nginx** — see `deploy/nginx.conf`. Symlink it into `sites-enabled` and
`nginx -t && systemctl reload nginx`.

**Queue workers (Supervisor)** — see `deploy/supervisor-queue-worker.conf`.
Copy to `/etc/supervisor/conf.d/`, then `supervisorctl reread && supervisorctl update`.

**Scheduler** — add one crontab entry (this drives the daily backup and queue
pruning defined in `routes/console.php`):

```
* * * * * php /var/www/audiobook/artisan schedule:run >> /dev/null 2>&1
```

**Log rotation** — set `LOG_CHANNEL=stack` / `LOG_STACK=daily` in `.env` so
Laravel's own log rotates itself (`config/logging.php`, 14-day retention by
default). For the Supervisor worker log, see `deploy/logrotate-audiobook`
(copy to `/etc/logrotate.d/`).

**HTTPS** — terminate TLS at Nginx (see `deploy/nginx.conf`); provision certs
with `certbot --nginx`.

**OPcache** — in `php.ini` for the FPM pool: `opcache.enable=1`,
`opcache.validate_timestamps=0`, `opcache.jit=tracing` (PHP 8.4), and re-deploy
with `systemctl reload php8.4-fpm` after each release so the cache picks up
new code (since `validate_timestamps=0` disables automatic invalidation).

**Backups** — `php artisan app:backup` dumps the database and archives
`storage/app/{books,audio}` into a zip under `storage/app/backups`, pruning
anything older than `--keep-days` (default 14).
It's scheduled daily at 02:00 via `routes/console.php`; ship the resulting
zips off-server (e.g. an S3 `rclone` cron job) for real disaster recovery.

## Storage layout

Uploads are private, kept off `storage/app/public`, and served only through
the authenticated `stream`/`download` API endpoints:

```
storage/app/books        original uploads (PDF/DOCX/TXT/MP3/WAV)
storage/app/audio        processed audio
storage/app/backups      app:backup output (see Deployment)
```
